# [Web ASCII Art Generator Bot](https://horr1ble171.github.io/web_ascii_art_generator_bot/)

Этот проект представляет собой современное веб-приложение (Telegram Mini App) для мгновенного преобразования ваших изображений в стильный ASCII-арт.

---

## ✨ Основные возможности

*   🖼️ **Мгновенная обработка:** Быстрая генерация ASCII-символов прямо в браузере с использованием HTML5 Canvas.
*   🎭 **Три режима набора символов:**
    *   `Простой` — классический вид.
    *   `Детальный` — высокая точность передачи нюансов.
    *   `Блоки` — стилизация под ретро-графику.
*   🎨 **Работа с цветом:**
    *   Сохранение оригинальных цветов изображения.
    *   Выбор из готовой палитры.
    *   Произвольный цвет через Color Picker.
*   ⚙️ **Гибкая настройка:** Регулировка детализации (ширины арта) в реальном времени.
*   📱 **Оптимизировано для Telegram:**
    *   Интеграция с Telegram Web App API.
    *   **Тактильная отдача (Haptic Feedback)** при взаимодействии с элементами.
    *   Адаптивный интерфейс с удобной выдвижной панелью управления.
*   💾 **Экспорт:** Сохранение результата в формате PNG.

## 🛠 Технологии

*   **Frontend:** Чистый JavaScript (ES6+), HTML5, CSS3.
*   **Графика:** Canvas API для попиксельной обработки изображений.
*   **Интеграция:** Telegram Web App SDK.
*   **Стиль:** Современный темный интерфейс с акцентом на мобильный UX.
